Now that we’re comfortable with Python basics and data structures, it’s time to meet NumPy — one of the most important libraries for Machine Learning.

🔢 What is NumPy?
NumPy stands for Numerical Python. NumPy is a Python library used for working with arrays. It also has functions for working in domain of linear algebra, fourier transform, and matrices. NumPy was created in 2005 by Travis Oliphant.

Why it’s important:

1. ML works heavily with numbers, vectors, and matrices
2. NumPy makes these operations fast and efficient
3. It stores data in continuous memory, which makes computations quicker(this is called locality of reference)

📌 Key idea:
👉 NumPy helps ML models process large numerical data efficiently.
