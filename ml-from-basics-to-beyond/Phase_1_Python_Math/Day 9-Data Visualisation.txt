After working with NumPy and Pandas, the next important step in Machine Learning is data visualization.
Before building models, we must see and understand the data.

📊 What Are Matplotlib & Seaborn?

🔹 Matplotlib

A core Python library for creating plots and graphs

Used for basic visualizations like line plots, bar charts, histograms, and scatter plots

Created by John D. Hunter (2003)

🔹 Seaborn

Built on top of Matplotlib

Provides a higher-level and more visually appealing interface

Especially useful for statistical plots

Developed by Michael Waskom

📌 Key idea:
👉 Seaborn makes plots look better, Matplotlib gives you full control.

❓ Why Data Visualization Is Important in ML

Visualization helps to:

1️⃣ Understand data

Spot patterns, trends, and outliers

2️⃣ Communicate insights

Explain results clearly to others

3️⃣ Explore relationships

Identify connections between variables before modeling

📌 In ML, visualization often decides what preprocessing or model to use next.

🧠 When to Use Which Plot?

Line Plot → show trends over time

Bar Chart → compare categories

Histogram → understand data distribution

Scatter Plot → see relationships between two variables

Heatmap → visualize correlations or intensity

Pairplot → explore relationships among multiple variables

Visualization comes before model training

Which features matter
