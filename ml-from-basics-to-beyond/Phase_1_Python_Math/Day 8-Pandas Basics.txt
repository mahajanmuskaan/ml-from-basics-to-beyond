📘 Day 8: Pandas Basics(Series, DataFrames & Handling Real Data)

After NumPy, the next essential tool for Machine Learning is Pandas.
If NumPy handles numbers efficiently, Pandas helps us work with real-world datasets.

🐼 What is Pandas?

Pandas is an open-source Python library used for data analysis and data manipulation.
It is built on top of NumPy and is designed to work with structured data like tables, CSV files, and datasets.

📌 Created by Wes McKinney (2008)

❓ Why Do We Use Pandas in ML?

Pandas makes working with data easier because it:

Handles missing data cleanly

Allows adding/removing columns easily

Aligns data automatically

Supports powerful group-by operations

Works well with time-series and tabular data

📌 Key idea:
👉 In ML, most of the time is spent understanding and preparing data, not training models — Pandas helps here.

📦 Core Pandas Data Structures

🔹 Series

One-dimensional labeled array

Similar to a single column in a table

Holds one data type

Used for:

Time-series data

Single feature values

🔹 DataFrame

Two-dimensional table (rows × columns)

Can store different data types in different columns

Mutable (can change size and values)

Used for:

Datasets

CSV files

Real-world structured data

📌 Simple difference:
👉 Series = single column
👉 DataFrame = full table

🧠 loc vs iloc (Quick Intuition)

loc → select using labels (column names, row labels)

iloc → select using index positions

📌 Use loc when you know names.
📌 Use iloc when working with positions.
