📘 Phase 2 – Data Handling & Preprocessing
Day 15: Categorical Encoding (Turning Categories into Learnable Signals)

Most Machine Learning models cannot understand text values like Male, Female, Debit Card, or Mobile Phone.

👉 So we need to convert categories into numbers.
This process is called Categorical Encoding.

🔄 What Is Encoding?

Encoding means converting data from one format to another so that machines can process it.

📌 In ML:

Text → Numbers

Categories → Numerical signals

Without encoding, models will fail or behave incorrectly.

🧱 Types of Categorical Encoding
1️⃣ One-Hot Encoding

Each category is converted into a separate binary column (0 or 1).

Example idea:

Gender → Gender_Male, Gender_Female


📌 Key points:

No order is assumed between categories

Safest for nominal data (no natural order)

✅ Best used for:

Gender

City

Payment mode

2️⃣ Label Encoding

Each category is assigned a unique integer.

Example idea:

Male → 1
Female → 0


📌 Important caution:

Numbers may imply an order

Can mislead models like linear regression

✅ Best used for:

Tree-based models

When order is meaningful or harmless

3️⃣ Ordinal Encoding

Similar to Label Encoding, but explicitly preserves order.

Example idea:

Low → 0
Medium → 1
High → 2


📌 Use only when categories have a real ranking.

⚖️ One-Hot vs Label vs Ordinal (Quick Guide)
Encoding Type	Assumes Order	Best For
One-Hot	❌ No	Nominal categories
Label	⚠️ Implicit	Tree models
Ordinal	✅ Yes	Ordered categories

📌 Rule of thumb:
👉 If there’s no natural order, prefer One-Hot Encoding.
