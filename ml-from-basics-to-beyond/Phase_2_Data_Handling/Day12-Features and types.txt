PHASE 2: Data Handling & Preprocessing
📘 Day 12: What Is a Feature?(Types of Features in Machine Learning)

Once we have a dataset, the next important question is:
👉 What information from the data will the model actually use?

That information is called a feature.

🔍 What Is a Feature?

A feature is an individual measurable property or input variable used by a Machine Learning model to make predictions.

Dataset → full table

Feature → each column (input information)

Example:

House Price Dataset
Features: size, location, number of rooms
Target: price


📌 Key idea:
👉 Features are the inputs that help a model learn patterns.

🧱 Main Types of Features
🔢 1️⃣ Numerical Features

Numerical features are numbers that represent quantities.

Examples:

Age = 25

Salary = 50,000

Temperature = 30.5

Types:

Discrete (countable): number of students, number of rooms

Continuous (measurable): height, weight, time

📌 ML use:
👉 Used directly in calculations and models.

🔤 2️⃣ Categorical Features

Categorical features represent categories or labels.

Examples:

Gender: Male / Female

City: Delhi, Mumbai, Bangalore

Payment method: Cash / Card / UPI

Types:

Nominal (no order): colors, cities

Ordinal (ordered): low, medium, high

📌 ML note:
👉 Categorical data must be encoded into numbers before modeling.

🔁 3️⃣ Binary Features

Binary features have only two possible values.

Examples:

Yes / No

True / False

0 / 1

📌 ML use:
👉 Common in classification problems.

🕒 4️⃣ Date & Time Features

These come from timestamps or dates.

Examples:

Order date

Login time

Year, month, day extracted from date

📌 ML use:
👉 Often transformed into:

day

month

weekday

hour

🧠 Derived / Engineered Features

These are new features created from existing ones.

Examples:

Age group from age

BMI from height & weight

Total spending from multiple purchases

📌 Key idea:
👉 Good features can improve model performance more than complex algorithms.

⚖️ Quick Summary
Feature Type	Example
Numerical	Age, salary
Categorical	City, gender
Binary	Yes / No
Date-Time	Order date
Engineered	BMI, age group
🧠 Why Features Matter in ML

Models learn only from features

Better features → better predictions

Poor features → weak models

📌 Important truth:
👉 Feature quality matters more than model complexity.
